# Startpage
### A simple yet elegant homepage
With Unified Search, you can search your bookmarks, search the web, or type any URL directly. 
[Try it out!](https://lfils658.github.io/startpage/)

## Features
 - Import bookmarks
 - Customize search engine (Google, Bing, or DuckDuckGo)
 - Current date/time display
 - Current weather for your location (Location permission required)

## Privacy-Focused
 - Your bookmarks and search engine selection are stored locally via a cookie.

## Intstallation
 1. Set your browser's start page to `https://lfils658.github.io/startpage/`
 2. Set your browser's new tab page to `https://lfils658.github.io/startpage/`. NOTE: Some browsers will not allow you to set a custom new tab page. To remedy this, you can install a custom new tab page extension or switch to a better browser.
 3. Customize your search. On the start page, click the settings icon and select your search engine of choice from the dropdown menu.
 4. Add your bookmarks via the settings menu on the start page. Set a NAME and ALTNAME for every URL that you input.
